## Scheduling and scope

Reconcile the three source sheets first. Develop the reusable kits through small visible examples, then finish the 18th Street/Glessner neighbours as the calibration block before expanding north and south. The table is a dependency plan, not an unauthorised re-ranking of existing queue work. Model and detail tickets with disjoint structure files can run independently once shared components land. All building packages remain individually replaceable.

A package is one bounded demonstration. Hero envelopes and detail finishes have separate tickets. Small rows use shared components but keep separate records. Rear lanes, large estate annexes and block closures must be split further before claiming if actual mapped quantities exceed one run. The estimate is not permission to mark half a facade or an unbaked model as complete. Recovery commits should include source data, recipe and current render checkpoints.

The block acceptance rows require their complete front/rear programme, the matching E20/E28/E35 parcel-interface package, relevant adjacent context from X01–X04/E02, and any current Glessner repair that affects comparison. E02 is an explicit successor workflow for extra visible background polygons; the initial 91-row register cannot prove those additional polygons are complete.
